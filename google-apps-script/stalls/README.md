## 導入

1. 対象スプレッドシートを開く。
2. `拡張機能` → `Apps Script`を開く。
3. `Code.gs`の内容を貼り付ける。
4. HTMLファイル`PosterUploader`を追加し、`PosterUploader.html`の内容を貼り付ける。
5. 保存してスプレッドシートを再読み込みする。
6. `文化祭サイト管理` → `模擬店シートを初期設定`を実行する。
7. 初回だけ、スプレッドシートとGoogle Driveへのアクセスを許可する。

## 画像登録

1. `模擬店`シートで対象行を選ぶ。
2. `文化祭サイト管理` → `選択中の模擬店へ画像を登録`を開く。
3. 画像を選択してアップロードする。
4. DriveファイルID、閲覧URL、サイト用画像URLが同じ行へ自動入力される。

画像ファイル名は模擬店IDに合わせて、たとえば`s01.webp`として保存される。
Driveへ直接画像を追加した場合は、`画像フォルダと再同期`で同じIDの行へ反映できる。

## 運用上の注意

- 模擬店ごとにシートを分けず、1企画を1行として管理する。
- IDは年度途中で変更しない。
- Drive画像を公開サイトで表示するため、画像は「リンクを知っている全員が閲覧可」に設定される。
- 学校のGoogle Workspaceで一般公開が禁止されている場合は、画像配信用の別方式が必要。
- サイト用画像URLはDriveの配信仕様変更の影響を受ける可能性がある。安定性を最優先する場合は、アップロード後にGitHub Pages用画像へ同期する。
