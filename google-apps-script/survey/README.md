# アンケート回答のスプレッドシート連携

回答は、次のスプレッドシートへ保存されます。

- 入口アンケート: 「アンケート回答」シート
- 帰り際アンケート: 「帰り際アンケート」シート

`1wDIO_MeLV8o9ZM44BgvTqb_ZIHksMdkGRzdG73nCcHk`

## 設定手順

1. 対象のGoogleスプレッドシートを開く。
2. 「拡張機能」→「Apps Script」を開く。
3. Apps Scriptの `Code.gs` を、このフォルダの `Code.gs` の内容で置き換えて保存する。
4. 「デプロイ」→「新しいデプロイ」を選ぶ。
5. 種類は「ウェブアプリ」を選び、次のように設定する。
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 全員
6. 初回の権限確認を許可し、表示された `/exec` で終わるウェブアプリURLをコピーする。
7. サイトの `.env.local` に次を設定する。

```env
VITE_SURVEY_GAS_URL=https://script.google.com/macros/s/デプロイID/exec
```

8. サイトを再ビルド・再デプロイする。

GASのコードを変更した場合は、Apps Scriptの「デプロイを管理」から新しいバージョンを作成して再デプロイします。

ウェブアプリURLをブラウザで直接開いて、次のように表示されれば受信準備完了です。

```json
{"ok":true,"message":"鶴東祭アンケートの受信準備ができています。"}
```

## 面白かった企画の集計

「面白かった企画1〜3」は、帰り際アンケートシートのE〜G列へ別々に保存されます。
企画ごとの回答数は、次のように3列をまとめて集計できます。

```text
=COUNTIF(E:G,"もちもちタピオカ（体3A1）")
```

企画名を別のセル（例: N2）に一覧化する場合は、次の式を下方向へコピーできます。

```text
=COUNTIF($E:$G,N2)
```

帰り際アンケートはブラウザ内に回答済み状態を保存し、同じ端末・ブラウザからの再回答を防止します。
ブラウザのデータ削除や別端末からの回答までは、ログインを導入しない限り完全には防止できません。
